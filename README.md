# 🤖 똑똑한 기술 탐험 — 중1 기술·가정 4단원 학습자료

2022 개정 교육과정 중학교 **기술·가정** 네 번째 영역 「**지속가능한 기술과 융합**」 성취기준을 근거로 만든 인터랙티브 웹 학습자료입니다.

## 다루는 성취기준 (교육과정 MCP 조회 원문)

| 코드 | 성취기준 | 차시 |
| --- | --- | --- |
| [9기가04-05] | 정보통신과 인공지능 기술의 활용 사례를 탐구하고, 정보통신과 인공지능 기술이 우리 삶에 미치는 영향을 다양한 관점에서 평가한다. | 1차시 |
| [9기가04-06] | 정보통신과 인공지능 기술 관련 문제를 이해하고 해결 방안을 탐색, 실현, 평가함으로써 긍정적인 문제 해결 태도를 갖는다. | 2차시 |
| [9기가04-09] | 로봇에 활용되고 있는 제어 및 자동화 기술 등을 탐구하여 간단한 로봇을 제작하고 평가함으로써 창조에 대한 자신감을 갖는다. | 3차시 |
| [9기가04-12] | 기술적 문제에 대한 도전적 태도로 다양한 분야에 활용되고 있는 융합 기술의 사례를 탐구하고 미래의 기술 변화를 전망한다. | 4차시 |
| [9기가04-13] | 긍정적이고 공감하는 문제 해결 태도를 바탕으로 지속가능한 발전과 혁신을 위해 융합 기술 문제를 해결하고 과정과 결과를 평가한다. | 4차시 |

출처: 교육부 고시 제2022-33호 2022 개정 교육과정 (MCP sourceRef `kr-moe-2022-33-annex10`)

## 차시별 구성

- **1차시 정보통신·AI 기술과 우리 삶** — 메시지 부호화·전송·복호화 체험, AI 기술 영향 평가표(개인·사회·윤리 관점)
- **2차시 AI 기술로 문제 해결하기** — 학습 데이터 편향 모의 실험, 문제 해결 과정 순서 맞추기, AI 서비스 설계 워크시트
- **3차시 로봇의 제어와 자동화** — 센서·제어기·구동기 분류, 로봇 시뮬레이터(개회로 vs 폐회로), 생활 속 제어 방식 찾기
- **4차시 융합 기술과 지속가능한 미래** — 융합 기술 사례 해부, 지속가능성을 고려한 아이디어 카드 만들기
- **근거·성취수준** — 성취기준 원문, MCP 학습 주제 ID, 수업용 성취수준(상·중·하) 예시

각 차시에는 확인 문제와 성취수준 자기 점검이 있고, 입력 내용은 학생 브라우저(localStorage)에만 저장됩니다.

## 사용한 교육과정 MCP

- [korean-secondary-learning-map-mcp](https://github.com/raphysicst-create/korean-secondary-learning-map-mcp) v0.3.0
- 조회 흐름: `list_curricula`(중학교) → `get_learning_roadmap`(기술·가정) → `get_standard`(성취기준 원문) → `search_topics`(연결 학습 주제·평가 관점)

## 구성 방식

외부 라이브러리 없이 HTML·CSS·JavaScript 단일 파일(`index.html`)로 구성되어 GitHub Pages에서 바로 동작합니다.

> 성취수준(상·중·하)은 성취기준 문장을 근거로 수업에 맞게 재구성한 예시이며, 교육부·국가교육위원회의 공식 성취수준이 아닙니다.
