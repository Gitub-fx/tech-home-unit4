핵심 개념

📡

정보통신 기술

정보를 만들고, 부호로 바꾸어 전달하고, 받아서 다시 이해할 수 있는 형태로 바꾸는 기술이에요. 스마트폰, 인터넷, 위성통신, 사물인터넷(IoT)이 모두 여기에 속해요.

🔁

통신 체제

입력(정보 생성) → 과정(부호화 → 전송 → 복호화) → 출력(정보 이용)으로 이어지고, 결과를 확인해 다시 반영하는 되먹임이 있어요.

📊

학습 데이터

AI는 사람이 준 데이터에서 패턴을 배워요. 데이터가 한쪽으로 치우치면 AI의 판단도 치우치는데, 이것을 데이터 편향이라고 해요.

🛠️

기술적 문제 해결 과정

🤝

책임 있는 AI 활용

개인정보 보호, 공정성, 투명성을 생각하며 기술을 만들고 사용해야 해요. 결과가 기대와 달라도 원인을 찾아 고쳐 나가는 태도가 중요해요.

핵심 개념

👀

센서 (감지)

빛, 소리, 거리, 온도 같은 주변 정보를 감지해 전기 신호로 바꿔요. 사람의 눈·귀·피부 같은 역할이에요.

🧩

제어기 (판단)

센서 신호와 프로그램을 바탕으로 무엇을 할지 판단하고 명령을 내려요. 사람의 뇌 같은 역할이에요.

⚙️

구동기 (동작)

모터처럼 명령을 받아 실제로 움직이는 장치예요. 사람의 근육 같은 역할이에요.

개회로 제어 (열린 제어)

정해진 순서대로만 동작하고, 결과를 다시 확인하지 않아요. 예) 타이머로 정해진 시간만큼 굽는 토스터

폐회로 제어 (닫힌 제어)

센서로 결과를 확인해 다시 제어에 반영(되먹임)해요. 예) 설정 온도를 맞추려고 스스로 조절하는 에어컨

자동화란 사람이 직접 조작하지 않아도 기계가 정해진 작업을 스스로 해내도록 하는 기술이에요. 공장 자동화(조립 로봇), 사무 자동화, 가정 자동화(스마트홈) 등으로 우리 생활에 쓰여요.
